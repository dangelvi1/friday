# Proposed rule — keep existing AGENTS.md

Dispatch explicit computer targets through their actual routes. Loopback refers to the device making the browser request, not the home server. Never claim a main-PC attempt from a current-device call, silently fall back to another device, or report opened search pages as analyzed/verified evidence. Keep authentication/device gates and require user attention for consent/challenge pages rather than bypassing them. Do not invent startup/configuration for a Local Agent missing from the supplied source.
