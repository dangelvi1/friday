## Still requires real-PC/site validation

No actual WordPress credentials were supplied, connected or used here. AITAN's public URL was supplied by the owner; cloud network policy blocked independent public-site inspection, which does not establish that the site is down. Test the actual canonical https://aitanservices.com address, REST availability, dedicated user's roles/Application Password and hosting/security behavior from FRIDAY. The transport implements public-DNS validation and address pinning, TLS hostname verification, redirect refusal, a request timeout and response size cap; no live external TLS behavior was proved by the controlled transport tests. DNS lookup itself has no separate application timeout.

WordPress core provides no atomic compare-and-set across independent FRIDAY/native editors: checks are best effort and an external edit can race after preflight. Use hosting backups/staging and avoid simultaneous external edits. Content source preview is text, not theme/layout rendering. Native title/excerpt do not override SEO plugins automatically; only actually exposed supported writable string meta is editable. New content starts as an unpublished draft; publication requires another exact review. Native uncertain writes are not automatically retried. Source restore does not undo native website changes or erase private tables.

Media uploads, page-builder layouts, theme/plugin changes, bulk publishing, automatic SEO crawling and AI website redesign remain pending. No customer portal/server, paid ad launch, live analytics or fabricated API success was introduced.
