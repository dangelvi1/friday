# First real-PC test

After installation/build/restart, close all old FRIDAY tabs, hard-refresh and reconnect chat/voice. Use your private dashboard, not a published policy as proof of deployment.

1. Open AITAN Marketing Studio → Nationwide → Google Ads Manager. Existing companies/plans should remain. If this is your first Ads setup, explicitly initialize the workspace, configure developer/OAuth settings privately and authorize Google. Do not create a second advertiser account. The real callback is https://friday.dangelvi.com/marketing/google-ads/callback and must exactly match the web OAuth client/backend settings.
2. Use the direct Test connection dashboard button. No OpenAI disclosure is needed for this manual dashboard read. Actual Google permissions/version and developer access must work; a missing/rejected API request must not be described as a connection success. No ads launch from this test.
3. In FRIDAY chat, ask “Check Nationwide's Google Ads connection.” Confirm the new Share Ads information with OpenAI dialog appears. Leave the box unchecked; Allow must be disabled. Click Decline — use dashboard. No Ads tool operation should execute or private result appear in the conversational answer. Existing dashboard controls/data must remain available.
4. Repeat the request. Check the disclosure box and click Allow this request. FRIDAY may now run that one requested Ads operation and return its actual outcome. An API error is still an error; consent does not make Google access valid.
5. Ask a second conversational Ads question. It must show a fresh unchecked disclosure. Escape/Decline must not reuse the first grant.
6. Open a disclosure, then lock/sign out of FRIDAY. It must close without releasing Ads results. Sign in again; no old permission should persist.
7. For WordPress, initialize Website Manager, connect the canonical site with a dedicated Application Password and first create a small unpublished POST draft through an exact review. Verify the receipt and native WordPress draft before editing live content. New content is not published by draft approval.

After these pass, the privacy policy can describe the actual deployed consent behavior, subject to the remaining operational facts/contact/deletion owner. Publishing the privacy page itself is a separate explicit website approval; this installer does not do it. Google OAuth verification/approval is not guaranteed by a package test.
